# AI usage disclosure

This project is being developed with AI assistance. The actual tools and activities used should be updated as development proceeds.

## Current record

- **ChatGPT (OpenAI):** assisted with the game concept, design pillars, game design document, technical architecture, implementation prompt, initial JavaScript modules, CSS interface and automated test cases.
- **Enemy/game AI:** implemented as custom deterministic/procedural game logic (finite-state machines, grid pathfinding, sound thresholds and decoy-pattern memory). It is not an LLM, does not call a hosted inference API and is not a trained machine-learning model.
- **Runtime AI dependency:** none. The game is designed to run offline after the static files have loaded, subject to browser support and any externally loaded fonts.
