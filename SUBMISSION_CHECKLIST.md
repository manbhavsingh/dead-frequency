# Loadout AI Game Competition — submission checklist

Competition page: <https://app.loadout.xyz/jam>

The current competition page states that entries close **6 November 2026 at 15:00 UTC (20:30 IST)**. Re-check the live page before submission in case the organizer changes the schedule or eligibility rules.

## Entry requirements

- [ ] Entrant is 18+ and authorized to submit the game and footage.
- [ ] One entry per person.
- [ ] AI made a genuine contribution to game development; describe it accurately.
- [ ] Actual game footage is captured (not a concept-only trailer).
- [ ] Publish a public X post with at least 15 seconds of gameplay footage.
- [ ] Tag `@loadoutprotocol` in the X post.
- [ ] Submit the public X post URL in the Loadout form.
- [ ] Fill game title, pitch (maximum 120 characters), X handle, contact email, solo/team status, development stage and AI-use description.
- [ ] Check optional fields deliberately. Token-launch interest is optional and does not affect judging; no token launch is required to enter or win.
- [ ] Save confirmation of submission.

## Release checks

- [ ] Public game link opens in a clean browser session.
- [ ] First-time player can understand the controls.
- [ ] At least one complete mission can be won.
- [ ] Sound decoys visibly propagate and change guard behaviour.
- [ ] Jammer, detection, extraction, restart and mute controls work.
- [ ] Test on a normal desktop browser; capture console errors and fix critical ones.
- [ ] Check responsive layout and keyboard focus.
- [ ] Update README with the verified public game link.
- [ ] Update AI_USAGE and ASSET_CREDITS with actual provenance.
- [ ] Do not claim untested features or fabricated gameplay metrics.

## Judging focus

The live page lists gameplay potential (40%), originality (25%), execution (20%) and development plan (15%). Likes and token-launch interest do not affect scoring.

## Current status

This repository currently contains an early playable prototype and automated logic tests. Public deployment, full browser playtesting, final footage and entry submission are not yet verified.
