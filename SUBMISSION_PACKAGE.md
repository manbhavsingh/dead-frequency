## Game description

DEAD FREQUENCY is a retro-inspired stealth extraction game where sound is your weapon. Infiltrate three increasingly hostile sectors, manipulate enemy hearing with signal decoys, disable security relays, recover encrypted memory fragments and escape before Quiet-Net identifies your patterns. Guards investigate sound origins, remember repeated decoy locations and pursue the last position they can actually detect. Cameras sweep exposed lanes, while crouching, sprinting and limited jammer charges create meaningful stealth choices.

**Core hook:** The city learns your lies. Make it hear the wrong thing.

## Originality and AI contribution

The distinctive design is the acoustic stealth loop: sound propagates through different map materials; guards investigate sound origins; repeated decoy locations increase suspicion; and the player must decide when to create noise, remain quiet, use a jammer, or move through exposed areas.

**AI-use disclosure draft (review for accuracy before submitting):**

> AI-assisted development tools were used for coding support, iteration, documentation and browser-based QA. The in-game enemy behaviour is implemented in the project code using deterministic finite-state machines, grid pathfinding, line-of-sight checks, acoustic propagation, suspicion and short-term memory of repeated decoy locations. The shipped game does not call an external generative AI service during gameplay. Original game rules, level layouts, tuning and final integration were reviewed and tested during development.

Do not claim that the game trains a machine-learning model. The current enemy adaptation is authored game logic and memory-based behaviour, not a learned neural network.
